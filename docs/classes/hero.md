# **英雄** <Badge type="warning" text="WIP" />

或许你获得了强大的装备，或许你觉醒了什么力量，或者你体内流淌着神的血。也有可能只是为了赎罪。
但无论如何，你都借此获得了成为「英雄」的资格。
不过，在这里、在这个世界。英雄无关品格与节操。

> ——只有一件事是肯定的，你做到了别人做不到的事情。

或许是独自一人击败了恐怖的怪兽，或许是你以一己之力解决了困扰他人许久的巨大难题。也有可能是你驯服了奇异的生物。
有的事情，对他人而言，是做不到的。但对于「英雄」而言，没有做不到这个词。

## 核心能力

### 1级

选择这个职业后，你确定最多 **2 条[试炼]**；之后你每提升 2 个英雄职业等级，都可以再增加或修改一条[试炼]。

可能得的[戒律]类型：*不攻击狗；不对女性下杀手；不进入水中。* 除此之外，你必须一马当先。英雄就是如此。

::: warning 违反[戒律]
一旦违反了这些[戒律]，你的职业能力失效，直到你在休息时花费 **8 小时**与 **5 资产**（或等价的物品）来重新定下[戒律]（类型不可更改）。
:::

#### 试炼 <Badge type="warning" text="WIP" />

[戒律]为你带来了力量，每条[戒律]都会赋予你新的[祝福]。

1. **野兽杀手** —— 你是最精湛的猎人。
   - **戒律**：—
   - **祝福**：一场遭遇战一次，你在对抗[野兽]时，你可以重新掷一次骰子，然后你选择你想要的结果。

2. **水面行者** —— 你抗拒水，也许是水抗拒你。
   - **戒律**：你不能浸泡在水里，当然淋浴可以。
   - **祝福**：一日一次，你获得水面行走能力，持续：职业等级/分钟。

3. **复仇者** —— 你的过去被某种生物、现象伤害了。
   - **戒律**：在你面对你选择的生物或者现象时，你不能主动脱离战斗。
   - **祝福**：你选择一种生物或者现象。一日一次，你在进行与这些选择内容相关的检定时，骰子结果+1。

4. **神之血**
   - **戒律**：—
   - **祝福**：你的体内流淌着神的血脉。你获得[神力解放（特异能力）]：一日一次，你在本轮中的所有行动获得+1的额外加值。你的攻击被视为你选择的神明的属性。

5. **恩典** —— 你获得了恩典。
   - **戒律**：无
   - **祝福**：你的初始购物资产增加15。

#### 英雄的象征

你选择你携带的一件物品，作为你的象征。在你携带这件物品时，你获得攻击/防御/技能（选择一种）的[检定加值]。

- 1级时为 **1**，5级时为 **2**，10级时为 **3**。
- 如果这件物品不慎遗失或毁坏，则你需要 **24 小时**的时间来重新寻回或修复。

### 2级

从[通用专长]或者[职业专长]里选择一个。

### 3级

#### 英雄气概

你的社交、恐吓，对抗心灵能力时获得加值。**3级 +1，6级 +2，10级 +3**。

#### 勇气

你振奋你的勇气，对于英雄而言，勇气可化作力量、可止住伤口、也可以让你完成你平常做不到的事情。一日一次，选择一种下列内容。

| 名称 | 效果 |
| --- | --- |
| **勇往直前** | 你在对抗困难地形的负面效果时获得加值，加值为你的职业等级/2（向下取整）。持续职业等级/轮。 |
| **跨越** | 你获得额外的移动距离，加值为职业等级×2。持续职业等级/轮。 |
| **力量** | 你的攻击检定获得加值，加值为你的职业等级/2（向下取整）。持续职业等级/轮。 |
| **无情** | 你的伤害结算时额外增加1D4（5级为1D6，10级为1D10）。伤害类型与你造成伤害的类型相同。持续职业等级/轮。 |
| **无畏** | 你获得减伤，数值为你的职业等级/2（向下取整）。持续职业等级/轮。 |
| **同情** | 你恢复生命，数值为职业等级×5%。 |
| **抗拒死亡** | 在你即将受到足以使你濒死的伤害时，如果过量伤害低于你最大生命值的10%，则你本次伤害结算后生命值为1。除此以外，正常结算濒死状态。 |
