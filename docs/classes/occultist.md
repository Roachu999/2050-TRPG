# **灵修士** <Badge type="warning" text="WIP" />

你是一个神秘学爱好者，从各种各样的渠道——网络论坛、街头闲谈、神秘古籍，甚至是寓言故事里「学到」了一些东西。
虽然真假参半，但你的热情又足以让你学习很多东西。
直到那一天，你跨越了帷幕。你发现了，它们都是存在的。
你兴奋的决定用你的「经验」来工作。

左手拿着圣银手枪，右手桃木十字架。左臂纹着双头鹰，右臂纹着卢恩符文。脚踩天罡步，嘴里喊着“妖魔鬼怪快离开”。

## 核心能力

### 1级

**灵修手册**：你把你的「知识」汇集了起来，编写成册。也可能是你的手机、平板电脑，甚至可能是你的「记忆宫殿」、用特殊的密码雕刻在首饰上。
总之你有了一套方法论。虽然有效，但你可能不知道是哪个部分起了效果。
首先，你获得 **6 点[灵修点]**，每次长休恢复。

**知识整理**：你整理了自己的知识，对一个目标进行调查，直到下次长休，你对这个目标的所有动作获得+1环境加值。

**灵修仪式**：你可以施展仪式来帮助你或者你的朋友。
如果你选择进行灵修仪式，每消耗一个灵修点可以多选择一个目标，投掷一个 D6，并根据骰子的数值确定一个效果：

| D6 | 效果 |
| --- | --- |
| 1 | 获得额外的1D6伤害加值 |
| 2 | 获得简单情报 |
| 3 | 获得抗性 |
| 4 | 获得额外的+2命中加值 |
| 5 | 获得+1幸运加值 |
| 6 | 获得10点虚假生命 |

**经验主义打击**：你的经验告诉你，在对抗某些存在时，可能攻击特定的部位可能更有效，也可能特殊的道具能够帮助你。
在你进行一次打击时，你支付一个灵修点，你可以用你的[精神能力]替代[肉体能力]进行攻击检定。
这次攻击的重击范围翻倍（19-20），且在命中后，投掷一个 D6，并根据下表获得效果：

| D6 | 效果 |
| --- | --- |
| 1 | 目标受到额外伤害 |
| 2 | 目标被推离10尺 |
| 3 | 目标的抗性降低 |
| 4 | 目标目盲一轮 |
| 5 | 目标被震慑一轮 |
| 6 | 目标开始逃离你，直到你的下个回合开始 |

从[通用专长]或者[职业专长]里选择一个。
