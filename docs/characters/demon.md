# **第二类恶魔** <Badge type="warning" text="WIP" />

你是恐惧、你是愤怒、你是怜悯、你是傲慢。也或许你是狼人（野兽）、是吸血鬼（吸血）、是杀人魔（杀害）。
但你并非渴求血与肉，杀戮与暴力的存在。
你是概念的化身，是人类的渴望、是恐惧，也是爱。
你虽然有着人的外形，但你的本质是人所定义的概念。

> ——「与古典恶魔可能只有名字相似」某恶魔学家
