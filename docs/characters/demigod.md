# **半神** <Badge type="warning" text="WIP" />

你的身体里流淌着神的血液，或许你的双亲里也有一名半神，或许是在你们家族的过去继承了这股力量，你只是返祖了而已。

- **[属性]**：6/6/6。
- **类型**：[<Badge type="info" text="人" />](/core/types) / [<Badge type="info" text="神" />](/core/types)

## 1级

选择你的[神力类型]，并获得[神力类型]对应的效果。

> **神力觉醒**（[超自然能力] · 每日一次）
> 你的所有数值（包括检定、伤害、属性）获得+1特异加值，持续你的等级/轮。

但你的食材费在计算时+1。

## 2级

从[通用专长]或者[职业专长]里选择一个。

## 3级

根据你体内流淌的神力类型，你获得不同的元素抗性/减伤。在你[神力觉醒]时，你的攻击伤害额外增加你的[神力类型]属性1D6。
