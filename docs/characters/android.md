# **人形 (Android)** <Badge type="warning" text="WIP" />

你并非是「机器」，只是你的心灵现在寄宿在钢铁的身体里。
你的知能和常人无异，会哭、会笑、会愤怒、会悲伤。精巧的模拟皮肤覆盖在你钢铁的身体上，让你非凡的完美。  
或许你是在这个世界上诞生的新生命也说不定。  
也许……你是——由人所制造的新神。

- **类型**：[<Badge type="info" text="神" />](/core/types)

## 1级

你初始就拥有两个[义体插槽]，和选择并免费获得一个[初级军用义体]。
