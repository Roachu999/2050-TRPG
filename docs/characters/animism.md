# **精灵（Animism）** <Badge type="warning" text="WIP" />

直到你真正意识到自己与他人不同的时候，在你的央求下，你的父母告知了你真相。
你是个隐藏在这个世界里的异类。
你的父母或许只是从树中、从矿脉、从光、从气流里发现了你，也有可能是你的父母其中之一就是精灵。你是获得了智慧与人形的物质本质。
但你像一个普通的人一样长大，直到你再也抑制不住你身体里蕴含的力量。

- **[属性]**：分配 3、4、8 这三个数字为你的初始属性。
- **类型**：[<Badge type="info" text="兽" />](/core/types)

## 1级

你根据你的[来源]，选择 3 种对应的 1 环[魔法]来作为你的初始法表，并获得[来源]对应的效果。

## 2级

从[通用专长]或者[职业专长]里选择一个。

## 3级

你根据你的[来源]，选择 1 种对应的 3 环[魔法]来作为你的增加法表，以及一个 3 环法术位。
一日一次，你可以临时改变自己的形态，将你的一种核心属性选择进行更换，持续到下次长休。

::: tip 友情提示
精灵玩家对于属性的计算最好多准备一张表。
:::

## 4级

从[通用专长]或者[职业专长]里选择一个。

## 5级

### 万物有灵

你获得能够变成你选择的[来源]的能力，持续等级/轮。根据你的[来源]，你可能会变回火焰、气流、光。
在变身之后，你不会受到[物理类型]（斩击、穿刺、打击）的伤害。你的非法术攻击伤害类型会变为你的[来源]所表明的类型。
