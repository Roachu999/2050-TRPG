# **动作系统** <Badge type="warning" text="WIP" />

## [主要动作] ×1

用于执行需要主要行动的行为。

- 攻击
- 施法
- 其他明确标注为需要消耗[主要动作]的能力

进行攻击时，根据武器面板、专长等效果，选择进行一次攻击或多次攻击。多次攻击会根据武器的[攻击模式]和攻击次数获得相应的多重攻击减值：

| 攻击次数 | 多重攻击减值 |
| --- | --- |
| 第一次攻击 | -2 |
| 第二次攻击 | -5 |
| 第三次攻击 | -8 |

**多重攻击攻击专长**：

| 攻击次数 | 多重攻击减值 |
| --- | --- |
| 第一次攻击 | 0 |
| 第二次攻击 | -2 |
| 第三次攻击 | -4 |

## [附赠动作] ×1

用于执行迅速完成的操作。

- 拔出武器
- 收起武器
- 切换武器
- 更换弹药
- 使用部分消耗道具
- 其他明确标注为[附赠动作]的能力

::: warning
附赠动作不是[免费动作]，每轮只能进行一次。除非角色的专长、职业能力或其他效果允许额外获得[附赠动作]。
:::

## [驱动动作] ×1

用于操作义体、装备、道具效果等的动作。

- 激活已经处于启动状态的义体主动能力
- 启动尚未启动的义体
- 使用装备主动能力
- 其他明确标注为驱动动作的能力

驱动动作与附赠动作相互独立。

## [移动]

角色拥有一个由移动速度决定的[移动距离池]。在自己的回合中，可以自由分配和消耗移动距离。

例如：

```
移动10尺 → 攻击 → 再移动15尺 → 使用义体
```

只要没有超过本轮的移动距离即可。

## 自由时点动作

以上动作均属于自由时点动作。也就是说，只要满足使用条件，角色可以在自己回合中的任意时点使用对应动作。

例如：

```
移动 → 驱动动作 → 攻击 → 附赠动作 → 移动
```

或者：

```
附赠动作 → 移动 → 攻击 → 驱动动作
```

## 动作降级 (Action Downgrade)

PC 可以在自己回合的任意时间放弃本回合的[主要动作]，将其转化为以下一种效果：

1. 获得 1 次额外[附赠动作]
2. 恢复 50% 的总移动池
3. 恢复 1 次额外[驱动动作]，但不能使用本轮已经使用过的义体的主动能力。若角色配置了多个相同义体，则可以分别使用这些义体。

::: info 注
附赠动作、驱动动作与移动不可逆向升级为主要动作。
:::
