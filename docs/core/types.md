# **类型**

所有的生物都被分为**神、兽、人、异**四种类型。

## 神

诞生于信仰，诞生于思想。超越「人」之理解的类型。
像是体内流淌神之血，或是与神相关、由思想或者概念类型的生物都属于这个类型。

## 兽

诞生于土地，诞生于海洋。「人」自以为理解的类型。
像是龙、海妖、狮鹫这种，与人不同但又都是从物质中诞生的属于这个类型。

## 人

自我认知、自我确立。所谓的万物之灵长。
这就是「人」之本型。

## 异

完全不明，无法分类的类型。

::: tip 多重类型
有的生物会同时具备多个类型，在相关检值检定或计算时，同时获得好处和坏处。
:::
