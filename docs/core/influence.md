# **影响度与破坏力** <Badge type="warning" text="WIP" />

## 影响度 (Influence / 流量值) —— 危险的诱惑

> “只要没死人，一切皆可炒作。”

你在普通人面前展现超规格力量的程度，或者你在网络上引发的讨论热度。

**如何掩盖**：非常容易。只需要水军刷屏、买对冲热搜，或者某娱乐巨头跳出来宣布“这是我们新签的虚拟偶像/特技演员”，就能把水搅浑。

**流量变现**：你的战斗视频如果被包装成“极限跑酷”或“特效短片”，在网络上，你会获得收益。可能是来自对于「特效」的匿名打赏，也有可能是一些公司看上了你，准备让你去「干活」。

影响度分为 4 个等级：

| 等级 | 表现 |
| --- | --- |
| 0-3 | 此事平平无奇。虽然你的部分表现被发到了网上，但是在庞大的互联网里掀不起什么浪花。 |
| 4-6 | 一时热议。 |
| 7-9 | 网络红人。 |
| 10 | 天王巨星！ |

## 破坏力 (Destruction / 维稳成本) —— 纯粹的债务

> “你可以手搓火球，但如果你炸断了跨江大桥，谁来付修桥和安抚市民的钱？”

你的行动对城市基础设施、平民生命财产造成的不可逆转的物理破坏。

**如何掩盖**：极其困难且昂贵。你可以伪造视频，但你没法伪造一个市中心的百米陨石坑。这需要大批工程队连夜伪造“天然气管道爆炸”的现场，需要支付巨额的平民封口费/医疗费，甚至需要动用记忆修改技术。

**代价**：如果破坏的程度低，那你可能因为你的「出身」，不需要支付什么。或者仅仅只是交一笔「城市建设费」的税罢了。但你搞得太过火了，那就不好说了。

破坏力分为 4 个等级：

| 等级 | 表现 |
| --- | --- |
| 0-3 | 简单的物品损坏，花花草草、或许是路灯躺椅。总而言之，政府与企业轻松就能摆平。或者根本就没在意你。 |
| 4-6 | 在地面上砸出了大坑、使无关人员受伤但不至死、破坏家用汽车和大破建筑外墙也在这个等级。还算问题不大，只要交一笔城市建设费就可以解决。 |
| 7-9 | 无关人员死亡、建筑物永久摧毁、巨大恐慌。十分危险的程度，政府和企业会根据你的所作所为来决定是交极大的罚款（更有可能是背上一辈子还不完的债务）还是被派去执行没人干的脏活。 |
| 10 | 红色警报！Broken Arrow！Broken Arrow！ |

::: tip 影响度与破坏力的联动
你的影响度会影响你是否能够逃脱破坏力带来的问题。影响度 7 以上时，哪怕是 1 级的破坏也需要交一笔罚款。
:::
