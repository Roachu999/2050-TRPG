# **格斗家绝技** <Badge type="warning" text="WIP" />

## 猛虎硬爬山

> **猛虎硬爬山**（一日一次）  
> **发动前提**：你的一次徒手攻击在命中检定时确认[重击]。  
> **效果**：你的这次徒手攻击伤害结算时会穿透目标的物理抗性，同时目标被[震慑]一轮直到回合结束。  

## 古流「褐」

> **古流「褐」**（一日一次）  
> **发动前提**：对一个目标进行徒手攻击，命中检定前。  
> **效果**：你的这次徒手攻击独立计算 3 次单次攻击，每次攻击计算时单独掷骰子。独立进行[命中检定]和[伤害检定]，且独立计算[重击]。  
> 这三次攻击是独立攻击，不承受多重攻击减值。
