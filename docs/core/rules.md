# **规则 (早期测试)** <Badge type="warning" text="WIP" />

## 关于骰子

D20 规则。

只需要准备 **D4、D6、D8、D10、D20**，共计 5 种骰子。

### 伤害检定

D4、D6、D8、D10。

标准模板：

| 武器 | 伤害骰 |
| --- | --- |
| 轻型 | D4 |
| 中型 | D6 |
| 重型 | D8 |

**伤害骰提升**：提升到下一级。D10 提升到 2D6，以此类推。

### 多重攻击规则

- 第一次：-2
- 第二次：-5
- 第三次：-8

**多重攻击攻击专长**：

- 第一次：0
- 第二次：-2
- 第三次：-4

### 成对规则

伤害骰降低一个等级，但增加一个骰子。成对武器攻击被视为一次攻击，正常结算多重攻击。

| 类型 | 骰子 |
| --- | --- |
| 轻型成对 | 2D4 |
| 中型成对 | 2D4（一般带有额外效果） |
| 重型成对 | 2D6 |

## AC 和 BAB 计算

### 命中检定

计算 `ω = 你的 BAB - 攻击目标的 AC`，并以 `DC = 10 - ω` 确定命中检定难度。具体看下表：

| 差值 | DC |
| --- | --- |
| -10 | 20 |
| -5 | 15 |
| 0 | 10 |
| +5 | 5 |
| +10 | 0 |
