# **检定与动作轮** <Badge type="warning" text="WIP" />

## 遭遇战

### 准备轮

如果 PC 没有遭遇偷袭，则在正式战斗开始前进入准备轮。

在准备轮中，PC 可以：

- 拔出武器
- 切换武器
- 收起武器
- 启动允许战前启动的义体
- 进行其他明确允许在准备轮执行的行为

::: info
准备轮不属于正式战斗轮，因此不会消耗角色正常的主要动作、附赠动作或义体动作。
:::

### 战斗轮

正式进入战斗后，使用标准[动作系统](/core/actions)：

- 主要动作 ×1
- 附赠动作 ×1
- 驱动动作 ×1
- 移动距离池

如果被偷袭，则按照进入战斗状态前的配置进入战斗轮。
